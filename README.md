# CSLT Kế Toán – Trắc nghiệm ôn tập

Ứng dụng web ôn tập trắc nghiệm môn Cơ sở lập trình trong kinh tế (470 câu, 6 chương): luyện tập theo chương, luyện tập tổng hợp, thi thử có tính giờ, thống kê kết quả và giải thích từng câu.

Chạy hoàn toàn trên trình duyệt (một file `index.html`); lịch sử làm bài lưu trong LocalStorage của trình duyệt đang dùng.
